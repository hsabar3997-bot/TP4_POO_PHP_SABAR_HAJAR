# TP4 : Programmation Orientée Objet en PHP

**Réalisé par :** SABAR Hajar  
**Technologies :** PHP 8.2, Git / GitHub

## Structure du projet

* `tp_poo/partie0.php` : Introduction aux classes et objets (`Voiture`)
* `tp_poo/partie1.php` : Visibilité et encapsulation (`Personne`)
* `tp_poo/partie2.php` : Constructeurs, promotion de propriétés et destructeur
* `tp_poo/partie3.php` : Surcharge de propriétés (`__get`, `__set`, `__isset`, `__unset`)
* `tp_poo/partie4.php` : Méthode magique `__toString()`
* `tp_poo/partie5.php` : Sérialisation d'objets (`__serialize`, `__unserialize`)
* `tp_poo/partie6.php` : Héritage, `final`, `readonly` et classe `Etudiant`
* `tp_poo/partie7.php` : Débogage et correction de la classe `Compte`
* `reponses.md` : Réponses détaillées aux questions théoriques du TP

## Exécution en local

Lancer le serveur interne PHP à la racine du projet :

```bash
php -S localhost:8000
```

Accéder ensuite aux exercices depuis le navigateur via `http://localhost:8000/tp_poo/partie0.php` (jusqu'à `partie7.php`).
